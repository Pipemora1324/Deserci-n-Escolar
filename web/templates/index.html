La deserción alta también es una alerta social.

El tablero muestra que el promedio nacional de deserción en {{ ultimo_ano }} es {{ promedio }}%, pero algunos territorios se ubican muy por encima de esa referencia. El caso más crítico en el último periodo es {{ depto_critico }}, con {{ valor_depto_critico }}%.

Cuando un estudiante abandona el sistema educativo aumenta su exposición a trayectorias de informalidad, baja empleabilidad y vulnerabilidad frente a economías ilegales o violencia territorial. Por eso el dato no debe leerse solo como matrícula perdida, sino como una señal temprana para activar permanencia, acompañamiento psicosocial, transporte y conectividad.

Dato del modelo: la IA proyecta {{ prediccion_ia }}% para {{ ano_prediccion }} y usa un margen técnico de +/-{{ margen_modelo }} puntos para separar riesgo, estabilidad y resultados favorables.
Dato del tablero: {{ depto_destacado }} aparece con la deserción más baja del último periodo: {{ valor_depto_destacado }}%. Ese comportamiento sirve como referencia para comparar territorios con mayor presión de abandono.
Lectura del modelo

La IA funciona como un semáforo técnico.

El sistema no inventa conclusiones: toma la deserción real de {{ ultimo_ano }}, la compara contra la proyección nacional de {{ prediccion_ia }}% para {{ ano_prediccion }} y clasifica cada territorio con un margen de +/-{{ margen_modelo }} puntos.

La lectura correcta es preventiva: una deserción baja indica mayor permanencia escolar; una deserción alta señala estudiantes fuera del sistema y mayor necesidad de intervención institucional.

Uso esperado: priorizar acompañamiento, becas, transporte, conectividad, alertas tempranas y rutas psicosociales en los departamentos que superan el umbral de riesgo.
