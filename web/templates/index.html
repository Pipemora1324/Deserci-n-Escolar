Arquitectura técnica

Pipeline de datos

01 / INGESTA
API datos.gov.co

Extracción automatizada del dataset de deserción escolar (ji8i-4anb) con 50.000 registros por consulta.

02 / LIMPIEZA
PySpark + Pandas

Normalización de departamentos, eliminación de duplicados, corrección de tildes y estandarización de tipos numéricos.

03 / ANÁLISIS
ANOVA + Tukey HSD

Pruebas estadísticas con scipy.stats para detectar diferencias significativas por región, nivel y período.
