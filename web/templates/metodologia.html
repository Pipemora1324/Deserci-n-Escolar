Metodología del Sistema de Analítica

Descripción detallada de las fuentes de datos, el pipeline de procesamiento, los métodos estadísticos utilizados y las consideraciones éticas del proyecto Datos al Ecosistema 2026.

01 Fuente de datos

Los datos provienen del conjunto abierto publicado por el Ministerio de Educación Nacional de Colombia en el portal de datos abiertos datos.gov.co, bajo el identificador ji8i-4anb.

El dataset contiene estadísticas educativas anuales por departamento, incluyendo tasas de deserción por nivel educativo, cobertura escolar, reprobación, repitencia y puntaje de estudiantes. Es de acceso público bajo la licencia de datos abiertos del gobierno colombiano.

01
Extracción vía API

Módulo ingestion.py consume la API REST de datos.gov.co con límite de 50.000 registros por llamada, obteniendo los datasets de deserción escolar e indicadores ICFES.

02
Limpieza y normalización

Módulo cleaning.py estandariza nombres de departamentos (códigos DANE), corrige tildes, elimina duplicados y convierte porcentajes a valores numéricos.

03
Consolidación

Módulo main.py orquesta el pipeline completo, concatena datos reales con proyecciones del modelo y genera el archivo master_data_final.csv.

04
Análisis y visualización

Las vistas Django ejecutan los tres ANOVAs con scipy.stats, generan gráficos con matplotlib y exponen los resultados junto al dashboard Power BI.

03 Análisis estadístico ANOVA

El ANOVA de un factor (Analysis of Variance) es un método paramétrico que permite contrastar si las medias de dos o más grupos independientes difieren significativamente. Su estadístico F se calcula como:

F = (SCE / glentre) / (SCD / gldentro)   ·   Donde: SCE = Suma de cuadrados entre grupos, SCD = Suma de cuadrados dentro de grupos

Si el p-valor asociado a F es menor que el nivel de significancia α = 0.05, se rechaza la hipótesis nula. Criterio de decisión: p-valor < 0.05 → Rechazar H₀.

ANOVA 01 · Por Región
H₀: μ_Caribe = μ_Andina = μ_Pacífica = μ_Orinoquia = μ_Amazonia
H₁: ∃ i,j : μᵢ ≠ μⱼ

Resultado: F = 49.08, p < 0.001
Decisión: Rechazar H₀
ANOVA 02 · Por Nivel
H₀: μ_Transición = μ_Primaria = μ_Secundaria = μ_Media
H₁: ∃ i,j : μᵢ ≠ μⱼ

Resultado: F = 58.24, p < 0.001
Decisión: Rechazar H₀
ANOVA 03 · Por Período
H₀: μ_pre = μ_pandemia = μ_post
H₁: ∃ i,j : μᵢ ≠ μⱼ

Resultado: F = 3.82, p = 0.022
Decisión: Rechazar H₀
Post-hoc Tukey HSD

Cuando el ANOVA rechaza H₀, el método Tukey HSD (Honestly Significant Difference) identifica qué pares de grupos difieren entre sí. Controla la tasa de error Tipo I familiar manteniendo una tasa de error global ≤ α = 0.05. Se implementa mediante la función statsmodels.stats.multicomp.pairwise_tukeyhsd.

04 Limitaciones y consideraciones éticas
Datos agregados a nivel departamental. El análisis opera sobre promedios departamentales anuales, no sobre datos individuales de estudiantes. Las conclusiones aplican al nivel macro-territorial y no permiten inferir comportamientos individuales o de instituciones específicas.
Proyecciones con margen de error. El modelo de regresión lineal produce estimaciones con un margen técnico de ±0.5 puntos porcentuales. Las proyecciones son indicativas y no sustituyen el análisis de políticas sectoriales específicas.
Supuestos del ANOVA. El ANOVA asume normalidad de residuos y homogeneidad de varianzas. Para muestras grandes (n > 30 por grupo), el teorema central del límite garantiza robustez del estadístico F ante desviaciones moderadas de normalidad.
Uso responsable de datos abiertos. Los datos son de acceso público bajo licencia abierta del gobierno colombiano. No contienen información personal o sensible. El análisis tiene fines académicos y de política pública, enmarcado en el concurso Datos al Ecosistema 2026.
Variables de confusión no controladas. Factores como el conflicto armado, las condiciones climáticas, la presencia de grupos al margen de la ley y la infraestructura vial pueden influir en la deserción pero no están capturados explícitamente en el dataset analizado.
